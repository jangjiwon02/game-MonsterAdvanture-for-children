## Overview

You start in a fictionalized version of Chungju, South Korea, pick a starter monster, and explore town and countryside — battling wild monsters in the grass (and water), catching them, growing your party, and dueling other trainers over LAN.

The project is maintained as **two parallel implementations of the same rules**:

- **`web/`** — a single-file HTML5 Canvas build. This is the playable reference implementation; its behavior is the ground truth.
- **`unity/`** — a Unity 2D port targeting Android (primary) and Windows Standalone, extended with real-time LAN multiplayer.

[SPEC.md](SPEC.md) documents the shared, engine-neutral rules (stat formulas, damage, catch rate, map generation, etc.) so both builds stay behaviorally identical — verified by a shared "golden" test suite.

---

## Features

- Turn-based battles with a type chart, STAB, critical hits, and an opponent AI
- 19 species with individual values (IVs), effort values (EVs), and natures
- Wild encounters in grass and water (water-type species only appear in water)
- Catching, a healing center, a shop, and a school math-quiz minigame
- Daily login bonus, save/load, Pokédex tracking
- **LAN multiplayer** (Unity build only):
  - Auto room discovery over the same Wi-Fi (UDP beacon + direct probe fallback), or manual IP entry
  - Carries over your single-player save (same monsters, level, bag) into the shared world
  - Party battles — potions, switching, forced switch on faint — resolved server-side

## Tech Stack

| Component | Technology |
| --- | --- |
| Reference implementation | HTML5 Canvas, vanilla JavaScript |
| Game engine (port) | Unity 6000.6.2f1 (2D) |
| Multiplayer transport | Raw `System.Net.Sockets` — length-prefixed JSON over TCP (port 7777) + UDP room discovery (port 7778) |
| Game data | `data/game-data.json` (species, moves, type chart), generated by `data/extract.js` |
| Telemetry backend | Google Apps Script + Google Sheets |
| Target platforms | Web browser (reference build), Android (`com.chungju.monsteradventure`) / Windows Standalone (Unity port) |

No networking middleware (Mirror/Photon/etc.) — the LAN layer is hand-rolled and covered by EditMode socket tests.

## Getting Started

### Play the web version

Download the repository as a ZIP and extract it, or clone it:

```bash
git clone https://github.com/jangjiwon02/game-MonsterAdvanture-for-children.git
cd game-MonsterAdvanture-for-children
```

Open the downloaded `web/index.html` directly in a browser, or serve the repository root with a static file server. The **Web source** badge above links to the source file on GitHub.

### Open the Unity project

1. Install **Unity Hub** + **Editor 6000.6.2f1** (add the Android Build Support module if you want to build an APK).
2. Open the `unity/` folder as a Unity project.
3. Open `Assets/Scenes/Chungju.unity` in the Project window and press **Play**.

### Run the tests

EditMode tests live under `unity/Assets/Tests/EditMode` and cover both gameplay rules (parity with the web build) and LAN networking (real loopback sockets). Run them from the Unity Test Runner (**Window → General → Test Runner**), or in batch mode:

```bash
Unity -batchmode -runTests -testPlatform EditMode -projectPath unity -testResults results.xml
```

## LAN Multiplayer

From the title screen, choose **함께하기 (LAN)**, then:

- **방 만들기 (Create Room)** — host a game; your room is broadcast to the same Wi-Fi network.
- **방 찾기 (Find Room)** — auto-discover open rooms and pick one from a list.
- **주소로 접속 (Advanced)** — enter the host's IP manually, for networks that block broadcast traffic.

See [SPEC.md](SPEC.md)'s "멀티플레이(LAN)" sections for the full design history and known limitations.

## Telemetry

The Unity build can optionally report install/session/progress events to a Google Sheet, for classroom use (tracking whether students are able to install and play). It is **off by default** (no endpoint configured) and never affects gameplay if disabled or offline.

This feature handles real names and play data for minors — see [telemetry/README.md](telemetry/README.md) before enabling it, and keep the destination spreadsheet access restricted to yourself only.
