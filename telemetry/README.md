# 원격 현황 수집 (설치 수 · 진행상황 · 접속시간)

게임이 켜질 때/꺼질 때/저장될 때마다 Google 스프레드시트로 기록을 보낸다. 학생 실명(기존 명단)과 연결되므로,
시트 접근 권한은 본인만 갖도록 유지할 것 — 절대 "링크가 있는 모든 사용자에게 공개"로 바꾸지 말 것.

## 1. 스프레드시트 + Apps Script 만들기 (한 번만)

1. `sheets.google.com` 에서 새 스프레드시트를 만든다. 이름은 아무거나(예: "몬스터어드벤처 현황").
2. 메뉴 `확장 프로그램 → Apps Script` 를 연다.
3. 기본으로 열려 있는 `Code.gs` 내용을 전부 지우고, 이 폴더의 `AppsScript.gs` 내용을 그대로 붙여넣는다.
4. 상단 함수 선택 드롭다운에서 `setup` 을 고르고 ▶ 실행 버튼을 누른다.
   - 처음 실행하면 "승인 필요" 팝업이 뜬다 — 본인 계정으로 로그인 → "고급" → "이동(안전하지 않음)" 순서로 진행해서 허용한다(내가 만든 스크립트라 안전하다는 경고일 뿐).
   - 실행 후 스프레드시트에 `설치기록/접속기록/최신현황/요약` 탭 4개가 생겼는지 확인한다.
5. `배포 → 새 배포`를 누른다.
   - 유형: **웹 앱**
   - 설명: 아무거나
   - 실행 계정: **나**
   - 액세스 권한: **전체(익명 사용자 포함)** — 학생 기기는 구글 계정으로 로그인한 상태가 아니므로 이 설정이 꼭 필요하다.
6. 배포하면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec` 형태)을 복사한다.

## 2. Unity에 URL 연결

`unity/Assets/Scripts/Runtime/TelemetryClient.cs` 맨 위 `EndpointUrl` 상수에 그 URL을 붙여넣는다:

```csharp
public const string EndpointUrl = "https://script.google.com/macros/s/여기에복사한URL/exec";
```

이 값이 비어 있으면 아무 것도 전송하지 않으므로(네트워크 요청 자체를 안 함), URL을 넣기 전까지는 기존과 동일하게 동작한다.
URL을 넣은 뒤 APK를 다시 빌드해서 배포하면 그때부터 기록이 쌓인다.

## 3. 현황 보는 법

스프레드시트를 열어서 보면 된다(별도 대시보드 없음 — 이번에 그렇게 정함):

- **요약** 탭: 총 설치 수 / 접속한 플레이어 수 / 전체 누적 플레이 시간.
- **최신현황** 탭: 학생 이름별 "지금" 레벨·도감 수·소지금·누적 플레이 시간·마지막 접속 — 매번 새 줄이 쌓이는 로그가 아니라, 이름당 한 줄만 계속 덮어써서 항상 최신 상태만 보인다.
- **설치기록** / **접속기록** 탭: 원한다면 시간대별 로그를 그대로 볼 수 있는 원본 기록.

## 무엇이, 언제 전송되나

| 이벤트 | 보내는 시점 | 내용 |
|---|---|---|
| `install` | 기기에서 처음 실행될 때 딱 한 번 | 기기ID(무작위 UUID), 앱 버전 |
| `session_start` | 게임을 켜거나(또는 백그라운드에서 복귀) 이름 확인 직후 | 이름, 기기ID |
| `session_end` | 앱이 백그라운드로 가거나 완전히 꺼질 때 | 이름, 기기ID, 이번 접속 시간, 누적 플레이 시간 |
| `progress` | 저장이 일어날 때마다(센터·상점·퀴즈·포획 등 자연스러운 저장 시점) | 이름, 기기ID, 레벨, 도감 수, 소지금, 누적 플레이 시간 |

이름은 첫 실행 시 기존 명단(교사 1 + 학생 11)에서 직접 고르며, 저장 파일에 남아서 다음부터는 다시 묻지 않는다.
네트워크가 없거나 요청이 실패해도 게임 플레이에는 전혀 영향이 없다(조용히 무시하고 계속 진행).

## 개인정보 관련 메모

실제 미성년자 개인정보(이름 + 플레이 기록)를 인터넷으로 전송·저장하는 기능이다. 최소한으로 지킬 것:

- 스프레드시트 공유 설정을 "제한됨(본인만)"으로 유지한다.
- 더 이상 필요 없어지면 스프레드시트를 삭제하거나 `최신현황`/로그 탭 내용을 지운다.
- 이 데이터를 본래 목적(공익 근무 중 게임 운영 현황 확인) 밖으로 공유하거나 재배포하지 않는다.
